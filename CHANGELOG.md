# Changelog

All notable changes to TermGlide are recorded here. The project follows Semantic Versioning.

## [1.0.0] - 2026-08-06

### Added

- Supervised local Chrome/Chromium discovery, isolated launch, CDP control, crash detection, and
  temporary-profile cleanup.
- Interactive terminal browsing with keyboard, mouse, address-bar, reload, zoom, resize, and
  cancellation handling.
- Cell, half-block, quadrant, and braille screenshot projection with bounded decoding and output.
- `doctor`, `inspect`, `snapshot`, and `dump` automation commands.
- DOM, accessibility-tree, proxy, user-agent, viewport, image, JavaScript, and resource-limit
  controls.
